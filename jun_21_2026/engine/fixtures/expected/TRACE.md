Rules: rx pushout = `date_add(rx_runout, ds)`; rx reset = `date_add(dt, ds-1)`;
medical runout = `date_add(dt, ds-1)` (never pushed out); MAP_END = max(runouts);
new MAP when `dt > MAP_END`; discon = gap to next MAP (or to OBS_END for the last)

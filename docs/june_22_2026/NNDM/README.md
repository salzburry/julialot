# Superseded

`SUPERSEDED_nmdmprotocol_do_not_use.pdf` is a PDF of
`..._12_OLD DO NOT USE.docx` — the Word file says so in its own title bar. Do
not read criteria off it.

It is kept because it is the only copy in this repository that carries the
objectives, outcome definitions and analysis sections, so it is usable for
*scoping* what work remains. It is not usable for *definitions*.

Where it is known to be wrong: its §6.2.1.1 gives the 2L/3L block two bullets
(the line, and 12 months of CE before it). The CoAuth revision gives three,
adding "CE during follow-up for each cohort: CE of at least 3-months during
follow-up or death with no gaps in enrollment". The `Jul 28` build implements
three. Anything else in this file may be stale the same way.

The current protocol is not in this repository. Add it before taking a
definition from any file here.
